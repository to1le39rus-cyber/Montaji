# Монтажи дверей — финальная версия

Мобильное PWA для учёта монтажей, сервисов, дополнительных доходов и расходов.

- **Архив всех выездов** — вся история, включая вчерашние и завершённые монтажи.
- **Редактирование архива** — меняет исходную запись; финансовые итоги пересчитываются после сохранения.
- **Доп. доходы** — отдельные услуги вроде вскрытия замка.
- **Расходы** — транспорт, топливо, холка и другие затраты.
- **JSON backup** — полная восстанавливаемая копия.
- **Excel** — независимая таблица всей истории; при недоступности XLSX-библиотеки создаётся CSV, совместимый с Excel.

## Резервирование

Рекомендуется периодически скачивать JSON и Excel из архива. Основная рабочая копия также остаётся в localStorage браузера.

## Синхронизация

В коде предусмотрен realtime Firebase/Firestore sync через `onSnapshot`. В текущем репозитории Firebase Web App config оставлен пустым, поэтому приложение гарантированно работает local-first и не падает из-за отсутствующей конфигурации. Для общей базы на двух телефонах нужен действующий Firebase Web App config.

## Релиз

Проверены синтаксис новых JS-модулей, единый ключ данных `montaji-aa-data-v4`, архивное редактирование, JSON backup и Excel/CSV export. GitHub Pages build/deploy используется для публикации.
