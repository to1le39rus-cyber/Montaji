# Монтажи дверей — PWA MVP

Мобильное веб-приложение для записи монтажей дверей.

## Что уже есть

- календарь по месяцам
- 4 слота в день
- добавление и редактирование монтажа
- расходка отдельно по дню
- поиск по ФИО, телефону и адресу
- фильтры
- отчёты за месяц и год
- экспорт CSV
- резервная копия JSON

## Как развернуть на Vercel

1. Импортируй репозиторий в Vercel.
2. Framework Preset: **Other**
3. Build Command: оставить пустым
4. Output Directory: оставить пустым
5. Deploy

## Важно

Сейчас это MVP на localStorage.
Для совместной работы двух пользователей следующим этапом нужно подключить базу данных и авторизацию.
