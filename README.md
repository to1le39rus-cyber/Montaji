# Монтажи дверей — финальная версия

Мобильное PWA для учёта монтажей, сервисов, дополнительных доходов и расходов.

## Данные
- Все выезды хранятся в архиве: **Ещё → Архив всех выездов**.
- Архив редактируемый: изменение даты выполнения, статуса или суммы меняет исходную запись и пересчитывает финансовые итоги после перезагрузки.
- Дополнительные доходы и расходы учитываются отдельно.
- JSON — полная восстанавливаемая резервная копия.
- Excel — независимая таблица всей истории; если XLSX-библиотека недоступна, скачивается CSV, совместимый с Excel.

## Резерв
Рекомендуемый минимум: периодически скачивать JSON и Excel из архива. Данные также остаются в локальном хранилище браузера.

## Синхронизация
В коде предусмотрен realtime Firebase/Firestore sync. Сейчас репозиторий содержит безопасный пустой Firebase config, поэтому без подключённого проекта приложение работает локально и не падает из-за отсутствующей конфигурации. Для совместной работы двух телефонов потребуется подставить Web App config действующего Firebase проекта.

## Проверка релиза
- GitHub Pages build/deploy проверяется через Actions.
- Новые модули проходят синтаксическую проверку.
- Архив, редактирование, экспорт JSON/Excel и восстановление используют одну и ту же базу `montaji-aa-data-v4`.
