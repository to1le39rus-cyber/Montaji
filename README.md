# Монтажи АА — финальная версия

Мобильное PWA для учёта монтажей, сервисов, дополнительных доходов и расходов.

## Данные и архитектура

- Основная рабочая копия: `localStorage` в браузере.
- Архив: все выезды сохраняются и доступны через **Ещё → Архив всех выездов**.
- Редактирование архива меняет исходную запись; после сохранения приложение пересчитывает текущие финансовые итоги.
- Дополнительные доходы (например, вскрытие замка) и расходы (транспорт, топливо, холка и т.п.) учитываются отдельно.
- Резервная копия: **Ещё → Резервная копия → Экспорт JSON**.
- Табличная копия: **Ещё → Архив всех выездов → Excel**. При недоступности библиотеки XLSX автоматически создаётся CSV, который открывается в Excel.

## Важное правило резервирования

Перед крупными изменениями данных рекомендуется скачать JSON и Excel. JSON — полная восстанавливаемая копия приложения, Excel — удобная независимая таблица всей истории.

## Совместная работа

В коде предусмотрен local-first Firebase/Firestore sync с realtime `onSnapshot`. Для включения общей базы нужен реальный Firebase Web App config в `firebase-config.js`; без него приложение безопасно работает локально и не теряет данные из-за отсутствия Firebase.

## Проверка релиза

Каждый релиз публикуется через GitHub Pages. Перед выпуском проверяются:

1. сборка GitHub Pages;
2. наличие `index.html`, `app-v4.js`, архива, Firebase sync и конфигурации;
3. синтаксис новых JavaScript-модулей;
4. экспорт/восстановление данных;
5. логика архивного редактирования и пересчёта через исходное хранилище.

## Рабочая схема

**Сегодня** — текущие выезды.

**График** — планирование по датам и слотам.

**Деньги** — доходы, расходы и чистый результат.

**Клиенты** — база клиентов из всей истории.

**Ещё → Архив** — вся история без ограничения только ближайшими днями.
