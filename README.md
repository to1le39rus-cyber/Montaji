# Монтажи АА — production

Мобильное PWA для графика монтажей, клиентов, доходов, расходов и архива.

## Главный принцип

**Cloud Firestore — единственный источник правды.**

Приложение не хранит рабочую базу в `localStorage` и не работает по схеме local-first. Если интернет/Firestore недоступен, старая информация не показывается и новые изменения не принимаются.

## Общая работа

Два телефона входят через Firebase Authentication по подтверждённому email/password и подключаются к одному документу `appData/shared`.

- realtime обновления через Firestore `onSnapshot`;
- конкурентные изменения через Firestore transaction;
- отменённые записи сохраняются в истории;
- выполненные работы учитываются по фактической дате;
- доходы и расходы считаются отдельно и чистыми;
- JSON/CSV — резервный экспорт, не источник текущих данных.

## Production-файлы

- `index.html` — интерфейс;
- `app.js` — единственная рабочая логика;
- `firebase-config.js` — конфигурация Firebase;
- `firestore.rules` — доступ к базе;
- `styles.css`, `final.css` — UI;
- `firebase.json` — deployment;
- `MONTAZHI-AA-OPERATING.md` — правила дальнейшей работы.

Не создавать новые `app-vN.js`. Любые следующие изменения делаются в текущем production-коде после тестирования.
