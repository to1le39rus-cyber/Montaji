# CODEX TASK — Montaji Telegram Bot / Google Sheets

Цель: довести `telegram-bot/google-apps-script/Code.gs` до полностью рабочего Telegram-бота для ежедневных монтажей входных дверей. Основное хранилище — Google Sheets. Supabase и Cloudflare не использовать для новой версии.

## Что уже подготовлено

В коде уже есть меню, добавление монтажа, карточка, статусы, поиск, календарь, напарник, напоминания, листы Google Sheets и исходный список магазинов.

## Сделай самостоятельно

1. Проведи code review `Code.gs`.
2. Исправь любые ошибки и недоделанные сценарии.
3. Обязательно исправь `/start`: случайный пользователь без invite не должен видеть данные и счётчик монтажей. После `/start` без действующего invite показать только сообщение об отсутствии доступа.
4. Обязательно обработай callback `search` из главного меню.
5. Проверь callback-data с названиями магазинов: значения должны корректно проходить Telegram callback_data, либо используй безопасный ID/индекс магазина.
6. Используй `LockService` вокруг операций создания монтажа и записи reminder, чтобы два одновременных запроса не создали дубликаты.
7. При создании монтажа повторно проверяй занятость слота непосредственно перед записью.
8. Сделай нормальную обработку ошибок Telegram/Sheets: пользователь должен получать понятное сообщение, а ошибка не должна ломать webhook.
9. Не допускай доступа pending-пользователя к данным.
10. Проверь, что owner — первый пользователь, member — только пользователь, пришедший по действующему invite.
11. Invite должен быть одноразовым и иметь срок действия.
12. Проверь напоминания: утро 08:00, за час до слота 11:00/14:00, вечер 20:00. Повторная отправка должна быть невозможна.
13. Проверь timezone `Europe/Kaliningrad`.
14. Добавь функцию `setWebhook()` или понятную инструкцию для webhook.
15. Проверь `doGet` и `doPost`.
16. Проверь Google Apps Script manifest.
17. Не добавляй секреты в GitHub.

## Google Sheet

Один Spreadsheet с листами:

- `Монтажи`
- `Магазины`
- `Пользователи`
- `Сессии`
- `Напоминания`

`setup()` должен создавать структуру и первоначальный список магазинов.

## Секреты

В Script Properties должны использоваться:

- `SPREADSHEET_ID`
- `TELEGRAM_BOT_TOKEN`
- `BOT_USERNAME`

Если у тебя есть доступ к Google Apps Script / clasp и авторизованный аккаунт, выполни deployment самостоятельно.

Если доступа к Google аккаунту пользователя нет, не симулируй deployment. Подготовь точные шаги, которые пользователь должен выполнить сам.

После изменений:

- сделать git diff;
- проверить отсутствие токенов и секретов;
- создать commit;
- создать PR `telegram-bot-v1` → `Astera-smart`.
