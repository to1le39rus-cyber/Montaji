# Montaji Telegram Bot

Простой Telegram-бот для ежедневной работы с монтажами входных дверей.

## Цель

Убрать отдельное PWA-приложение из ежедневного процесса. Толя и напарник работают прямо в Telegram: смотрят монтажи, быстро добавляют заявку, получают напоминания и меняют статус.

## UX

Главный экран:
- 🔨 Сегодня
- ➕ Новый монтаж
- 📆 Календарь
- 📋 Все монтажи
- 🔎 Поиск
- 👥 Напарник

Карточка монтажа:
- дата и слот
- клиент
- телефон
- адрес
- магазин
- стоимость
- статус
- оплата
- комментарий

Быстрые действия:
- 📍 маршрут
- 📞 позвонить
- ✏️ изменить
- 🔄 перенести
- ✅ выполнен
- ❌ отменить

## Данные из старого приложения

Используются существующие сущности `stores`, `jobs` и их справочники. В старом MVP уже были 4 слота, статусы, оплата, поиск по ФИО/телефону/адресу и месячный календарь.

## Статусы

- Бронь
- Подтверждён
- Выполнен
- Перенос
- Отменён

## Напоминания

- утренний список монтажей;
- за 1 час до монтажа;
- вечером — список монтажей, которые не закрыты.

Часовой пояс по умолчанию: `Europe/Kaliningrad`, менять через переменную окружения.

## Совместная работа

Первый пользователь автоматически становится владельцем рабочего пространства. Владелец получает одноразовую ссылку-приглашение для напарника. Напарник видит и редактирует те же монтажи.

Роли:
- owner — полный доступ и управление приглашением;
- member — монтажи и статусы.

## Бесплатный стек

- Telegram Bot API + webhook;
- Cloudflare Workers Free;
- Cloudflare Cron для напоминаний;
- Supabase Free как база.

Cloudflare Workers Free сейчас даёт 100 000 запросов в сутки и до 5 Cron Triggers на аккаунт. Бот должен оставаться в пределах бесплатного тарифа при обычном использовании двумя людьми.

## Секреты

Никогда не коммитить:
- `TELEGRAM_BOT_TOKEN`
- `SUPABASE_SERVICE_ROLE_KEY`
- любые приватные ключи.

Публичный Supabase anon key из старого PWA не использовать для серверного бота.

## Deployment

Codex должен:
1. создать/обновить Worker;
2. применить SQL migration к существующему Supabase project;
3. добавить secrets;
4. deploy Worker;
5. вызвать Telegram `setWebhook` на URL Worker;
6. проверить `/start`, создание монтажа, просмотр сегодня, invite и напоминания;
7. исправить ошибки до зелёного smoke test.
