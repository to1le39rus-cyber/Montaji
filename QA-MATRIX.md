# МОНТАЖИ АА — QA matrix

## Release gate

Статические проверки не заменяют live-проверку, но каждая важная функция должна иметь проверяемый контракт.

| Область | Happy path | Ошибка/граница | Второй телефон | Перезагрузка |
|---|---|---|---|---|
| Загрузка БД | существующие данные видны | Firebase недоступен | — | данные те же |
| Создание монтажа | запись появляется | несколько монтажей в один день допустимы | появляется | сохраняется |
| Редактирование | изменения видны | пустые обязательные поля | обновляется | сохраняется |
| Выполнение | доход появляется | повторное нажатие не удваивает доход | статус синхронный | сохраняется |
| Долг | долг появляется | сумма не исчезает из дохода | виден | сохраняется |
| Оплата долга | долг уменьшается | повторное нажатие безопасно | синхронно | сохраняется |
| Замер | отдельный тип | свободное время | синхронно | сохраняется |
| Замер → монтаж | связь сохраняется | повторная конвертация невозможна/понятна | синхронно | сохраняется |
| Расход | уменьшает чистыми | 0/отрицательная сумма запрещена | синхронно | сохраняется |
| Архив | история остаётся | случайное удаление невозможно | синхронно | сохраняется |
| Заметки | общие | ошибка notes не ломает shared | синхронно | сохраняется |
| Календарь | будущие и прошлые дни | 3+ монтажей в день не ломают историю | синхронно | сохраняется |
| Клиенты | поиск работает | дубли не плодятся без причины | синхронно | сохраняется |
| Backup | JSON создаётся | повреждённый JSON не затирает БД | — | — |
| Restore | валидный backup восстанавливается | подтверждение + плохой файл | — | сохраняется |
| Offline | старые данные не выдаются за актуальные | запись блокируется | — | после online reload |
| Mobile | iPhone Safari | клавиатура/safe-area | — | — |

## Business invariants

1. Отменённый выезд никогда не считается доходом.
2. Невыполненный выезд никогда не считается доходом.
3. Выполненная, но не оплаченная работа остаётся доходом и одновременно долгом.
4. Расход не является отрицательным доходом.
5. История не уничтожается физическим удалением.
6. Количество монтажей в день **не имеет жёсткого максимума**. Слоты 10:00–12:00, 14:00–16:00 и 3-й слот — удобные пресеты, а не ограничение бизнеса.
7. Замер не должен случайно становиться монтажом без явного действия.
8. Ошибка `notes` не должна делать `shared` недоступным.
9. Ошибка сети не должна маскироваться под пустую рабочую базу.
10. Два клиента должны видеть один и тот же source of truth.
