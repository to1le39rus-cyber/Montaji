# Монтажи АА — финальный аудит архитектуры

## Роли проверки

### Стратег
- Один production-контур.
- Один источник истины: Cloud Firestore.
- Никакого расхождения данных между телефонами.
- Offline не считается рабочим режимом данных: при отсутствии сети данные не показываются и записи не принимаются.

### Архитектор / логик
- Убрана схема local-first с периодическим пушем localStorage в Firestore.
- Изменения выполняются транзакциями Firestore, чтобы конкурентные изменения не затирали друг друга.
- Realtime обновление выполняется через onSnapshot.
- При потере соединения состояние очищается из интерфейса.

### Безопасность
- Старые анонимные права доступа признаны недостаточными для production: Firebase прямо предупреждает, что anonymous auth не является заменой постоянному входу, а правило `auth != null` даёт доступ любому аутентифицированному пользователю.
- Production-версия использует email/password и подтверждённый email.
- Firestore rules запрещают доступ анонимным пользователям.

### Дизайн / UX
- Сохранён существующий мобильный интерфейс и структура разделов.
- Добавлен понятный экран входа.
- Статус базы явно показывает: онлайн / нет связи.
- При отсутствии интернета приложение не показывает устаревшую базу.

### Программист
- Один `app.js` содержит интерфейс, бизнес-логику, Firebase Auth, Firestore, realtime и архив.
- Старые `app-v*.js`, `archive.js`, `firebase-sync.js`, Supabase и secure-app варианты исключены из production-загрузки.
- `index.html` подключает только один рабочий JS.

### Тестировщик
Обязательные сценарии перед релизом:
1. Вход подтверждённым пользователем.
2. Неверный пароль.
3. Добавление выезда.
4. Одновременное добавление с двух телефонов.
5. Редактирование.
6. Удаление.
7. Выполнение с датой выполнения.
8. Перенос.
9. Отмена.
10. Доход.
11. Расход.
12. Архив.
13. JSON backup/restore.
14. Потеря сети — данные скрываются.
15. Возврат сети — данные снова загружаются с сервера.

## Важное

Существующая запись `appData/shared` сохранена как основной документ, поэтому текущая структура данных не требует автоматического преобразования. Новая версия читает и изменяет этот документ напрямую.
