# Подключение Supabase

## Что уже подготовлено

- `supabase/schema.sql` — таблицы, триггеры и RLS-политики
- `supabase/seed.sql` — список магазинов

## Порядок действий

1. Зарегистрируйся в Supabase и создай новый проект.
2. Открой **SQL Editor**.
3. Запусти сначала `schema.sql`.
4. Потом запусти `seed.sql`.
5. В Supabase открой **Authentication > Users** и зарегистрируйся в приложении первым пользователем.
6. После регистрации открой SQL Editor и выполни:

```sql
update public.profiles
set role = 'admin'
where email = 'ТВОЙ_EMAIL';
```

7. Второй пользователь сможет зарегистрироваться позже и получит роль `viewer` по умолчанию.

## Что это даст

- ты — `admin`: создаёшь, редактируешь, удаляешь
- монтажник — `viewer`: только смотрит
